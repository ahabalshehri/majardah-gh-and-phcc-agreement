# نموذج بيانات الاتفاقية بين المراكز الصحية

نموذج ويب لجمع بيانات الاتفاقية بين المراكز الصحية بقطاعي المجاردة وبارق. الردود تُرسل مباشرة إلى جدول بيانات Google Sheet خاص، ولا يطّلع مقدمو الطلبات على ردود بعضهم البعض.

## إعداد استقبال الردود (مرة واحدة فقط)

1. أنشئ جدول بيانات جديد في Google Sheets (يبقى خاصًا بحسابك فقط).
2. من القائمة: **الإضافات (Extensions) → Apps Script**.
3. احذف أي كود موجود، والصق محتوى ملف [apps-script.gs](apps-script.gs) من هذا المستودع.
4. اضغط **نشر (Deploy) → نشر جديد (New deployment)**.
   - النوع: **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
5. اضغط **Deploy**، وامنح الأذونات المطلوبة عند الطلب.
6. انسخ رابط **Web app URL** الناتج.
7. افتح [index.html](index.html) وابحث عن السطر:
   ```js
   var SUBMIT_URL = "PASTE_YOUR_APPS_SCRIPT_WEB_APP_URL_HERE";
   ```
   واستبدل النص برابط الـ Web App الذي نسخته.
8. احفظ الملف وارفعه (commit + push).

من هذه اللحظة، كل رد يُرسل من النموذج يُضاف كصف جديد في جدول البيانات تلقائيًا، مع الطابع الزمني. لتصدير الردود إلى Excel: من Google Sheets اختر **File → Download → Microsoft Excel (.xlsx)**.

## النشر العام (اختياري)

لإتاحة رابط عام للنموذج (لأطراف خارج المستودع الخاص)، فعّل **GitHub Pages** على فرع `master` لهذا المستودع، أو استضف ملف `index.html` على أي استضافة ثابتة (Netlify، Vercel، إلخ).
